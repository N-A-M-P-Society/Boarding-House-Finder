Phase 2: Complete HTTP Method Test Suite (Postman)
1. GET AUTH TOKENS
1.1 Landlord Authentication
Method: POST

URL: https://<your-project-id>.supabase.co/auth/v1/token?grant_type=password

Headers: apikey: <YOUR_SUPABASE_ANON_KEY>, Content-Type: application/json

Body:

JSON
{
  "email": "landlord.davao@gmail.com",
  "password": "password123"
}
Save output as LANDLORD_TOKEN.

1.2 Student Authentication
Method: POST

URL: https://<your-project-id>.supabase.co/auth/v1/token?grant_type=password

Headers: apikey: <YOUR_SUPABASE_ANON_KEY>, Content-Type: application/json

Body:

JSON
{
  "email": "blue.knight1@addu.edu.ph",
  "password": "password123"
}
Save output as STUDENT_TOKEN.

2. POST (Create Resources)
2.1 Create Boarding House (POST)
Method: POST

URL: http://localhost:3000/api/boarding-houses

Headers: Authorization: Bearer <LANDLORD_TOKEN>, Content-Type: application/json

Body:

JSON
{
  "house_name": "Knight's Haven Dormitory",
  "address": "E. Jacinto St, Davao City",
  "description": "Student housing near AdDU campus.",
  "latitude": 7.0715,
  "longitude": 125.6131
}
Output: Returns house_id: 1.

2.2 Create Room (POST)
Method: POST

URL: http://localhost:3000/api/rooms

Headers: Authorization: Bearer <LANDLORD_TOKEN>, Content-Type: application/json

Body:

JSON
{
  "house_id": 1,
  "room_number": "101",
  "monthly_rate": 3500,
  "capacity": 2,
  "amenities": "Aircon, WiFi"
}
Output: Returns room_id: 1.

2.3 Submit Booking (POST)
Method: POST

URL: http://localhost:3000/api/bookings

Headers: Authorization: Bearer <STUDENT_TOKEN>, Content-Type: application/json

Body:

JSON
{
  "room_id": 1,
  "amount": 3500.00,
  "payment_method": "GCash",
  "receipt_url": "https://storage.unirent.ph/receipts/gcash-ref-10029384.png"
}
Output: Returns booking_id: 1.
